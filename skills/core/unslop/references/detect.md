# Detect mode

Name each pattern found, quote the line, give the fix in a few words. Do not rewrite.

- Read [patterns.md](patterns.md) first, and name each finding by its rule number and name from there, so findings stay comparable across runs.
- The tests in `SKILL.md` decide whether a passage is a finding: below the density test's bar, a single device is not reported.
- When nothing fails, say so in one line.
