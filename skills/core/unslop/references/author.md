# Author mode

Hold the tests in `SKILL.md` while the user writes; return nothing. When handed content and asked to write, draft it under the same tests and return the draft.

- Pick the register first; it decides voice and how much first person the draft carries.
- Put the outcome the reader needs in the first sentence (test 6), then the reason, then background.
- Draft only from what the source or the user supplied. A gap stays a gap: state what the source does not show rather than filling it.
- For a passage the tests alone do not settle, read [patterns.md](patterns.md).
